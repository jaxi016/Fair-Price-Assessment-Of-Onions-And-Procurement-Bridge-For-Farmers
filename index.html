2. Market reference prices

How the demo decides

A — visibly larger, rounder, healthy-colour bulbs
B — average marketable bulbs
C — visibly small or irregular bulbs

Weighted value = the five-group Grade A/B/C mix × configured ₹/kg × mass. The time factor is calculated automatically every 30 minutes from the benchmark time, using the configured decay rate and retained-value floor.

A single-onion inspection uses exactly 4 views of the same onion; batch mode uses 5 layers × 4 views. It validates each image with offline onion-image cues as a transparent prototype heuristic, not a trained ML classifier.
